# QuietRoom website

Static site for [QuietRoom](https://quietroom.hiimobapps.cn/): landing page, privacy policy and support (English at `/`, Simplified Chinese at `/zh/`). Served by GitHub Pages from `main`; custom domain via `CNAME`.

Edit copy in `tools/build.py`, then run `python3 tools/build.py`. No analytics, cookies or third-party requests.
